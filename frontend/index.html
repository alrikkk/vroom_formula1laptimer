01 // THE LAP

what makes
a lap fast?

Every lap time in Formula 1 is an ongoing negotiation between two opposing physical dynamics.

FEATURE 01
macro race progression (lap)
As laps advance from 1 to 71, cars shed onboard fuel weight while track grip evolves. In our classical ML models, lap number acts as the primary proxy for this macro progression across the race distance.
feature: lap ∈ [1, 71]
FEATURE 02
stint tire progression (tire_age)
Tracks cumulative clean flying laps completed on a tire set since pit exit. Within a single final stint, tire age is mathematically collinear with race lap, offering no additional out-of-sample predictive power.
feature: tire_age = lap - pit_lap

QUESTIONS

frequently asked questions

which formula 1 race was selected? +
The 2019 Austrian Grand Prix (Race ID 1018) held at the Red Bull Ring in Spielberg. External historical FIA race bulletins document dry running (31°C ambient, 50°C track) with 0 red flags and zero safety cars (contextual verification; not part of Kaggle lap_times.csv).
how was the data cleaned before training? +
We applied a strict sequential 3-rule cascade: (1) removed 11 pit-stop in-laps, (2) removed 11 immediate out-laps (P+1), and (3) checked for slow outlier laps (> 1.5× driver median), removing 0. Starting with 705 raw laps, exactly 683 clean flying laps were retained.
why did you use a stint-based split instead of random? +
Random splitting causes temporal data leakage because consecutive laps share track and tire states. By training on earlier stints (280 laps) and testing strictly on each driver's final stint (403 laps), we measure true forward pace prediction.
why classical machine learning instead of neural networks? +
Option A explicitly mandates classical machine learning. Ridge Regression and Random Forest Regressors offer full mathematical transparency, exact reproducible coefficients, and high performance on structured tabular race telemetry.

03 // SYSTEM ARCHITECTURE

technical methodology

Systematic pipeline design, boundary conventions, and classical modeling constraints.

01

data source & integrity

KAGGLE F1 (1950–2024)

Standardized timing records from lap_times.csv, pit_stops.csv, results.csv, and races.csv by Rohan Rao were utilized. Source files are strictly preserved without synthetic augmentation or modification.

02

race selection rationale

SPIELBERG // RACE ID 1018

Selected for its unbroken green-flag running: the 2019 Austrian Grand Prix at the Red Bull Ring. All 20 selected-race drivers were classified in the official results; 5 completed the full 71-lap distance and 15 finished one lap behind.

Externally Verified Race Conditions (Official FIA Bulletins): Dry 31°C ambient, 50.2°C track, 0% precipitation, 0 safety cars, 0 red flags (historical context; not in Kaggle lap_times.csv).
03

sequential 3-rule cleaning cascade

705 RAW → 683 CLEAN

Non-flying laps are eliminated in strict sequential order:
• Rule 1: Pit-stop in-laps removed (11 laps).
• Rule 2: Immediate out-laps (P+1) removed (11 laps).
• Rule 3: Outlier laps > 1.5× driver median removed (0 laps).
Exactly 683 clean flying laps retained across all 10 classified finishers.

04

feature space engineering

BASELINE VS ENHANCED

• Baseline: grid (qualifying starting slot) + lap (macro race progression).
• Enhanced: grid + lap + tire_age.
• Tire Age Convention: Resets to 0 at the first retained flying lap of each stint (Lap 1 for Stint 1; Lap P+2 after pit stop), incrementing by 1 on each subsequent lap.

05

chronological stint partition

ZERO TEMPORAL LEAKAGE

Chronological stint partition testing true out-of-stint extrapolation:
• Training: Earlier stints across 10 drivers (280 laps, 41.0%).
• Testing: Final stint across all 10 drivers (403 laps, 59.0%).
Strict zero data leakage between training and testing partitions.

06

classical regression algorithms

NO NEURAL BLACK BOXES

• Ridge Regression: L2 regularized linear model inside a StandardScaler pipeline (α=1.0).
• Random Forest Regressor: Non-linear decision tree ensemble (100 estimators, max depth 6). Pinned to RANDOM_STATE = 42.

07

evaluation & benchmarks

RMSE & MAE IN SECONDS

Evaluated strictly on the unseen final stint test set:
• Random Forest Baseline: RMSE 0.8043s | MAE 0.6448s.
• Ridge Regression Baseline: RMSE 2.0461s | MAE 1.7534s.
Non-linear tree ensemble outperformed linear regression by ~1.24s RMSE.

08

collinearity & stint dynamics

SCIENTIFIC CONCLUSION

Adding tire_age slightly worsened test RMSE (+0.023s Ridge; +0.028s RF). Because the test set is strictly the final stint, tire age linearly tracks race lap progression (tire_age = lap - constant). The baseline models already capture macro pace progression through grid slot and lap number.
